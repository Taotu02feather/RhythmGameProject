# Taotu Rhythm Game

A rhythm game framework that explores automatic music analysis and chart generation.

一个探索音乐分析与自动谱面生成的节奏游戏框架。


---

## Introduction | 项目介绍

Taotu Rhythm Game is an experimental project focused on building a flexible rhythm game system.

The project aims to allow users to import their own music files, analyze musical characteristics, and generate playable rhythm game charts.

Taotu Rhythm Game 是一个致力于构建灵活节奏游戏系统的实验性项目。

项目目标是让用户能够导入自己的音乐文件，通过分析音乐特征，并生成可游玩的节奏游戏谱面。


The project combines music analysis, signal processing, and intelligent algorithms to explore new possibilities in rhythm game development.

本项目结合音乐分析、信号处理以及智能算法等技术，探索节奏游戏开发中的新可能。


---

## Main Features | 主要功能


### Music Import and Analysis | 音乐导入与分析

The system supports importing user-provided audio files and extracting important musical information.

系统支持导入用户提供的音频文件，并提取其中的重要音乐信息。


Current and planned capabilities include:

当前及未来计划支持：

- Beat and rhythm analysis  
  节奏与鼓点分析

- Tempo (BPM) estimation  
  速度（BPM）估计

- Audio feature extraction  
  音频特征提取

- Musical structure analysis  
  音乐结构分析


---

### Automatic Chart Generation | 自动谱面生成

The project explores methods for automatically generating rhythm game charts based on music characteristics.

本项目探索基于音乐特征自动生成节奏游戏谱面的方法。


The general workflow:

整体流程：

```
Music File
    ↓
Music Analysis
    ↓
Feature Extraction
    ↓
Chart Generation
    ↓
Rhythm Game Chart
```


---

### Flexible Rhythm Game Framework | 灵活的节奏游戏框架

The project aims to provide an extensible framework for different rhythm game designs.

项目旨在提供一个可扩展的框架，以支持不同类型的节奏游戏设计。


Possible directions include:

未来可能支持：

- Custom gameplay mechanisms  
  自定义游戏机制

- Adjustable difficulty levels  
  难度调整

- Music-synchronized visual effects  
  音乐同步视觉效果

- User-created charts  
  用户自定义谱面
